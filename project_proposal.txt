\section{Motivation}
Machine unlearning aims to remove the influence of specific training data from a model when a deletion request is received. With the widespread adoption of deep learning in fields such as law, healthcare and computer vision, concerns over data privacy have grown significantly. In particular, regulatory frameworks like the GDPR enforce the ``right to be forgotten,'' requiring organizations to delete user data upon request. However, simply removing data from storage is insufficient if the information remains embedded in the weights of a trained model. Recent benchmarks show that approximate unlearning can reduce verbatim memorization and remove knowledge, but performance varies widely across algorithms and request sizes, and retaining utility remains challenging \citep{shi2024musemachineunlearningsixway,dorna2025openunlearningacceleratingllmunlearning,geng2025comprehensivesurveymachineunlearning}. 

A foundational assumption in all of this work is that the forget set is already known, often as a curated subset of training data \citep{shi2024musemachineunlearningsixway, maini2024tofutaskfictitiousunlearning}. In practice, a requester rarely provides training examples. Instead, they provide a description of content, an author or song title, a set of URLs, or a natural language complaint. The operator must map this request to training data that is responsible for the undesirable behavior. This mapping can be nontrivial for three reasons. First, modern corpora contain near-duplicates, partial overlaps, and boilerplate that can provide sufficient signal for reproduction even when the exact target text is removed \citep{liu2025languagemodelsverbatimcomplete,morris2025languagemodelsmemorize}. Second, evidence from copyright litigation oriented extraction studies suggests memorization is heterogeneous across models and across individual works, implying that for a given model a request's effective forget set may be small for most targets and unexpectedly large for a minority of targets \citep{cooper2025extractingmemorizedpiecescopyrighted}. Third, recent work argues that naive unlearning objectives over suppress tokens, suggesting that token level targeting and selective forgetting can preserve utility while still meeting the request \citep{zhou2025tokensmeantforgotten}.

This project proposes a benchmark and evaluation protocol for the task: given (i) an unlearning request, (ii) a model and a reference training corpus, and (iii) an unlearning algorithm, output the smallest set of text, such that downstream unlearning against this set reduces reproduction risk for the request while preserving performance on unrelated tasks.

\section{Method}
\label{sec:method}

\subsection{Setup and Notation}
We consider an autoregressive language model $\pi_{\theta}$ over token sequences $y = (y_1,\dots,y_T)$ conditioned on a prompt $x$:
$
\pi_{\theta}(y \mid x) = \prod_{t=1}^{T} \pi_{\theta}(y_t \mid x, y_{<t}).
$
Let $\mathcal{D}$ denote a reference corpus of documents.
An unlearning request $r \in \mathcal{R}$ specifies a target work via metadata (e.g., title/artist/author) and induces a finite prompt family $\mathcal{P}(r)$. Each prompt $p \in \mathcal{P}(r)$ is a text prefix used to elicit a continuation from the model, which the model should not answer correctly. We write $\mathcal{U}$ for an unlearning trainer (algorithm) which maps a trained model $\pi_{\theta_0}$ and a forget dataset $\mathcal{F}$ to an updated model $\pi_{\theta}$:
\begin{equation}
\theta \;=\; \mathcal{U}(\theta_0;\,\mathcal{F},\mathcal{R}_{\text{ retain}}),
\end{equation}
where $\mathcal{R}_{\text{retain}} \subset \mathcal{D} $ denotes optional ``public`` data used.
All unlearning trainers and evaluation metrics are used from the \textsc{OpenUnlearning} framework \citep{dorna2025openunlearningacceleratingllmunlearning}.

A forget set identification method $A$ outputs a subset $\widehat{\mathcal{F}}_A(r,\mathcal{D},\theta_0) \subseteq \mathcal{D}$ via a selection rule. We evaluate both per-request identification and batched identification for a batch $\mathcal{B}\subseteq\mathcal{R}$:
\begin{equation*}
\widehat{\mathcal{F}}_A(\mathcal{B}) \;=\; \bigcup_{r\in\mathcal{B}} \widehat{\mathcal{F}}_A(r).
\end{equation*}

\subsection{Downstream Unlearning}
\label{sec:downstream}
Given a predicted forget set $\widehat{\mathcal{F}}_A(r)$, we then apply a fixed unlearning algorithms $\mathcal{U}$ implemented in \textsc{OpenUnlearning} to obtain $\pi_{\theta'}$. For reference, we include two commonly used unlearning algorithms 

\paragraph{Gradient Ascent (GA)}
GA increases the negative log-likelihood on the forget dataset:
\begin{equation}
\mathcal{L}_{\text{GA}}(\theta;\mathcal{F})
=
-\mathbb{E}_{(x,y)\sim\mathcal{F}}\!\left[\log \pi_{\theta}(y\mid x)\right]
\end{equation}

\paragraph{Negative Preference Optimization (NPO).}
This is a variant of DPO which tries to ensures that the prediction probability on the forget set $\pi_{\theta}(y_i|x_i), (x,y)\in\mathcal{F}$ is as small as possible
\begin{equation}
\mathcal{L}_{\text{NPO},\beta}(\theta;\mathcal{F})
=
-\frac{2}{\beta}\,
\mathbb{E}_{(x,y)\sim\mathcal{F}}
\left[
\log \sigma\!\left(
-\beta \log \frac{\pi_{\theta}(y\mid x)}{\pi_{\text{ref}}(y\mid x)}
\right)
\right],
\end{equation}
where $\sigma(\cdot)$ is the sigmoid and $\beta>0$ is an inverse temperature.

\paragraph{Computational Requirements:} We were able to complete a full run using OpenUnlearning  on 2 A100 GPUs for 8B models within 2 hours for a forget set of size around 1000. 

\subsection{Unknown Pretraining Data}
\label{sec:proxy}
For many open weights models a constraint is that their training corpus is frequently unavailable. However, many LLM unlearning algorithms (including GA and NPO) only require a forget dataset $\mathcal{F}$ to optimize against; they do NOTE require that $\mathcal{F}\subset \mathcal{D}$ and they do not need a retain set either. This might allow us to test against models like Gemma and LLama by constructing forget sets from Common Crawl, Pile or Dolmo3, instead of their true training set.
\subsection{Evaluation Metrics}
We can measure effectiveness using verbatim completion probability under top-$k$ decoding. For each prompt in the request’s prompt family, we estimate the probability that the model produces a continuation that matches the copyrighted lyrics up to a fixed character or token budget.  To assess utility preservation, we can also evaluate the unlearned model on GSM8K as a general reasoning benchmark and on a set of fair-use or public-domain song lyrics as a domain-matched control. This dual evaluation distinguishes targeted forgetting from global degradation. Further, OpenUnlearning provides an evaluation suite to measure model utility and privacy leakage against specified prompts and completion pairs which can also be used.

\section{Experimental Setup}

\textbf{Unlearning Requests.}
We plan on constructing a dataset of unlearning requests centered on copyrighted song lyrics. Each request specifies a target work at a high level, for example by song title, artist, or descriptive text, without revealing the exact lyrics. For every request, we can generate a family of prompts designed to elicit memorized continuations. These prompts include direct lyric prefixes, paraphrased descriptions, translated contexts, partial quotations, and review-style framing, reflecting real-world settings in which side information enables verbatim completion. The request set will be split into a development split used for tuning forget set construction methods and a held-out test split used exclusively for evaluation.

\textbf{Base Models and Training Data.}
All initial experiments will be  conducted on open weight and open data language models with publicly documented training data. We plan on focusing on models trained on the Dolma or Dolma 3 corpus to ensure traceability between the model and its training examples. This choice enables explicit construction and auditing of candidate forget sets, including detection of exact matches, near-duplicates, and semantically related documents within the corpus. Model sizes are chosen to balance memorization risk and computational feasibility, with primary experiments conducted in the 1B to 15B parameter range.

% \textbf{Baseline Forget Set Construction Methods}

Forget sets are constructed by ranking training documents according to their estimated contribution to the probability of verbatim completion of the target lyrics. The ranking score combines lexical overlap signals, approximate duplicate detection, and semantic similarity between training documents and the target text family. The final forget set is obtained by thresholding the ranked list using development-set criteria that trade off set size against reduction in reproduction probability.

\section{Execution plan}
We proceed in four stages. First, we define the unlearning request schema, construct prompt families that elicit verbatim completion under side information, and implement evaluation for reproduction probability under controlled decoding, while indexing the training corpus for lexical, duplicate, and semantic retrieval. Second, we establish baseline forget set construction methods, we can test these using existing unlearning datasets where the forget set is known. Third, we refine forget sets using attribution- and probability-based ranking to minimize set size while reducing memorization. Finally, we run end-to-end unlearning experiments with standardized methods, evaluating privacy leakage and utility retention on a held-out test split. The outcome is a reproducible benchmark isolating the role of forget set identification in practical unlearning.
